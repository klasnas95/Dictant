# МАССА 2.0 — программа тренировок 188/80

Программа на набор массы для новичка (рост 188 см, вес 80 кг): зал 3 раза в неделю + дом 2 раза. Сделана для iPhone, всё хранится в одном HTML-файле и работает без интернета.

| Файл | Зачем |
|---|---|
| `MASSA_188x80.html` | Один самодостаточный файл (фото, шрифты, стили и код внутри). Его можно хранить на телефоне, в «Файлах», на Google Диске или в почте. |
| `index.html` | Тот же файл для публикации как сайт (GitHub Pages): подключает офлайн-кэш (`sw.js`) и `manifest.webmanifest`, чтобы приложение ставилось на экран «Домой». |
| `src/` | Исходники: контент (`data.py`), сборка (`build.py`), стили, код приложения, готовые кадры упражнений. |

## Что внутри

- **Программа**: День 1 (грудь, плечи, трицепс), День 2 (ноги, пресс), День 3 (спина, бицепс), домашняя тренировка. Разминка, подходы, повторы, веса-ориентиры и отдых.
- **Анимация каждого упражнения**: две фазы движения из фото, 67 упражнений.
- **Дневник подходов**: вес × повторы, автоподсказка веса по двойной прогрессии (+2,5 кг, когда все подходы на верхней границе), разгрузка при застое, рекорды.
- **Таймер отдыха** сам запускается после подхода. Экран не гаснет во время тренировки.
- **Замены**, если тренажёр занят, в один тап. Калькулятор блинов, разминочные подходы.
- **База упражнений**: фильтры по группам мышц и месту (зал или дом).
- **Прогресс**: графики веса тела и силы, история тренировок, замеры, экспорт и импорт резервной копии.
- **Питание**: норма калорий и БЖУ (Миффлин — Сан Жеор), меню на день, домашний гейнер, дешёвый белок, чек-лист дня.
- **Советы**: прогрессия, техника, сон, застой, боль, частые вопросы.

## Два режима на iPhone

1. **Встроенный просмотр** (тап по файлу в «Файлах», в почте или на Диске). JavaScript там не запускается, но всё равно работают вкладки, анимации, галочки подходов, счётчик подходов и таймер отдыха (он сделан на чистом CSS). После закрытия отметки не сохраняются.
2. **Полная версия в Safari**: дневник, графики, подсказки веса и сохранение данных. Удобнее всего опубликовать папку `massa/` как сайт на GitHub Pages и в Safari выбрать «Поделиться» → «На экран „Домой“».

## Пересборка

```sh
cd massa/src
pip install pillow fonttools brotli   # pillow нужен для иконок и кадров
python3 build.py                      # пишет ../MASSA_188x80.html, ../index.html, sw.js, manifest, иконки
```

Кадры уже лежат в `src/assets/img`. Скачивать их заново нужно, только если меняешь набор упражнений: см. `imgs.py` (переменная `MASSA_DL`).
