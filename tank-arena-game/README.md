# Tank Arena

Браузерная аренная игра-шутер на танках, вдохновлённая механиками diep.io.
Чистые HTML5 + CSS + JavaScript (Canvas API), без внешних библиотек и без загрузки чего-либо из интернета.

## Запуск

1. Откройте файл `index.html` двойным кликом или перетащите его в окно браузера (Chrome, Edge, Firefox, Safari).
2. Введите ник и нажмите «Начать».

Сервер, сборщик и установка чего-либо не нужны.

## Управление

| Клавиша / действие | Что делает |
| --- | --- |
| `W` `A` `S` `D` или стрелки | Движение |
| Мышь | Прицеливание (пушка поворачивается за курсором) |
| `ЛКМ` или `Пробел` | Стрельба (зажатая кнопка стреляет непрерывно) |
| `E` | Переключатель автострельбы |
| `C` | Переключатель автоповорота пушки |
| `1`–`8` | Вложить очко улучшения в стат (также клик по панели слева внизу) |

## Механики

### Арена
- Квадратная арена 4000×4000. Камера следует за танком игрока и постепенно отдаляется с ростом уровня.
- По краям арены стоят невидимые стены: танки и пули через них не проходят.
- Миникарта в правом нижнем углу показывает положение игрока и ботов.

### Полигоны
| Полигон | Цвет | Прочность | Опыт | Урон при контакте (в секунду) |
| --- | --- | --- | --- | --- |
| Квадрат | жёлтый | малая | 10 | 5 |
| Треугольник | красный | средняя | 25 | 10 |
| Пятиугольник | синий | высокая | 60 | 18 |
| Альфа-пятиугольник | тёмно-синий, большой | очень высокая | 260 | 35 |

Полигоны появляются случайно, после разрушения возрождаются через несколько секунд в новом месте.
При столкновении с танком полигон и танк толкают друг друга и наносят взаимный урон.

### Опыт и уровни
- Опыт начисляется за разрушение полигонов и за убийство танков (ботов или игрока).
- Полоса уровня находится внизу экрана.
- Максимальный уровень — 45.
- За каждый уровень выдаётся одно очко улучшения.

### Статы
У каждого стата максимум 7 вложений.

| Стат | Эффект |
| --- | --- |
| Health Regen | Скорость восстановления здоровья |
| Max Health | Максимальное здоровье |
| Body Damage | Урон при таране |
| Bullet Speed | Скорость пуль |
| Bullet Penetration | Сколько целей пуля может пробить |
| Bullet Damage | Урон пуль |
| Reload | Скорость перезарядки |
| Movement Speed | Скорость движения |

### Классы и эволюции
Эволюцию выбирает игрок на 15, 30 и 45 уровнях (появляется панель с вариантами).

- **15 уровень:** Basic → Twin, Sniper, Machine Gun, Flank Guard
- **30 уровень:** Twin → Triple Shot, Quad Tank; Sniper → Assassin, Overseer; Machine Gun → Gunner, Sprayer; Flank Guard → Tri-Angle, Quad Flank
- **45 уровень:** Triple Shot → Penta Shot; Quad Tank → Octo Tank; Assassin → Ranger; Overseer → Overlord; Gunner → Hyper Gunner; Sprayer → Shotgun; Tri-Angle → Falcon; Quad Flank → Hexa Flank

### Боты
- На арене 10–15 ботов со случайными именами, классами и уровнями (уровни около уровня игрока).
- Боты блуждают, охотятся на танки и полигоны, держат дистанцию, обходят стены и других танков, отступают при низком здоровье.
- Убитые боты возрождаются через несколько секунд.

### Интерфейс
- **Таблица лидеров** (справа вверху): топ-10 по очкам, игрок выделен.
- **Панель улучшений** (слева внизу): статы и количество очков.
- **Полоса опыта** (внизу экрана).
- **Экран смерти:** финальный счёт, уровень, время жизни, число уничтоженных танков и кнопка «Играть снова».

## Структура файлов

```
tank-arena-game/
├── index.html      разметка: холст, HUD, экраны старта/эволюции/смерти
├── style.css       стили интерфейса
├── README.md       эта инструкция
└── js/
    ├── config.js   размеры арены, баланс, статы, классы, полигоны
    ├── shapes.js   полигоны: отрисовка, урон, столкновения с танками
    ├── bullets.js  пули: полёт, время жизни, пробивание
    ├── tank.js     базовый танк: движение, стрельба, статы, опыт, отрисовка
    ├── player.js   игрок: клавиатура, мышь, автострельба и автоповорот
    ├── bots.js     ИИ ботов
    ├── ui.js       HUD, таблица лидеров, миникарта, панели и экраны
    └── main.js     игровой цикл, столкновения, камера, отрисовка
```

Игра использует цикл `requestAnimationFrame` с учётом `deltaTime` (ограничен 50 мс), столкновения — круговые хитбоксы.
