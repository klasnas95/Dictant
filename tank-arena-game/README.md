# Tank Arena

Браузерная 2D-игра в жанре arena tank shooter (по мотивам механик diep.io, с собственным оформлением).
Одиночный режим: вы против 12 ботов на большой арене с полигонами.

## Как запустить

Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari) двойным кликом.
Сервер, сборка и интернет не нужны: только HTML5, CSS и чистый JavaScript (Canvas API).

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | движение |
| мышь | прицеливание |
| ЛКМ / `Пробел` | стрельба |
| `E` | автострельба (вкл/выкл) |
| `C` | автоповорот пушки (вкл/выкл) |
| `1`–`8` | вложить очко в характеристику (или клик по панели слева внизу) |
| клик по карточке | выбор нового класса (панель слева вверху) |
| `Enter` | «Играть снова» на экране смерти |

Клавиши работают при любой раскладке, в том числе русской.

## Механики

- **Арена** 5000×5000 с невидимыми стенами по краям. Камера плавно следует за танком.
  В центре — «гнездо», где чаще появляются пятиугольники и живут альфа-пятиугольники.
- **Полигоны**: квадраты (10 опыта), треугольники (25), пятиугольники (130) и альфа-пятиугольники (3000).
  У них есть здоровье, при касании они наносят урон, после разрушения появляются заново.
- **Опыт и уровни**: опыт за полигоны и убийства ботов (половина их счёта), максимум 45 уровней.
  Полоса уровня и счёта — внизу экрана.
- **Прокачка**: за каждый новый уровень — очко улучшения. 8 характеристик, у каждой максимум 7 вложений:
  Health Regen, Max Health, Body Damage, Bullet Speed, Bullet Penetration, Bullet Damage, Reload, Movement Speed.
- **Эволюция** на 15, 30 и 45 уровнях:
  - 15: Twin, Sniper, Machine Gun, Flank Guard
  - 30: Triple Shot, Quad Tank, Twin Flank, Assassin, Hunter, Destroyer, Gunner, Tri-Angle
  - 45: Triplet, Penta Shot, Spread Shot, Octo Tank, Triple Twin, Ranger, Stalker (невидимость в покое),
    Predator, Streamliner, Annihilator, Sprayer, Booster, Fighter
- **Отдача**: каждый выстрел слегка отталкивает танк (у Destroyer — сильно, у Tri-Angle задние пушки разгоняют вперёд).
- **Пробивание**: пуля теряет «прочность» при каждом попадании; с прокачанным пробиванием она пролетает сквозь несколько целей.
- **Боты**: 12 ботов со случайными классами, уровнями и стилем игры (снайперы, таранщики и т.д.).
  Они блуждают, фармят полигоны, сражаются с ближайшими танками, убегают при низком здоровье,
  обходят препятствия и уклоняются от пуль. Убитые боты возрождаются через 3–6 секунд.
- **Интерфейс**: таблица лидеров (топ-10, игрок выделен), миникарта, уведомления,
  экран старта с ником и экран смерти со счётом, уровнем, классом, временем жизни и убийствами.
- После появления танк 3 секунды неуязвим (защита снимается первым выстрелом).

## Структура

```
tank-arena-game/
├── index.html      разметка, экраны и HUD
├── style.css       оформление интерфейса
└── js/
    ├── utils.js     математика, цвета, форматирование
    ├── config.js    константы, таблица опыта, полигоны, дерево классов
    ├── input.js     клавиатура и мышь
    ├── particles.js частицы и всплывающие надписи
    ├── shapes.js    полигоны
    ├── bullets.js   пули
    ├── tank.js      базовый класс танка (статы, стрельба, отрисовка)
    ├── player.js    танк игрока
    ├── bots.js      ИИ ботов
    ├── ui.js        таблица лидеров, миникарта, панели
    └── main.js      игровой цикл, столкновения, камера, рендер
```

Технически: игровой цикл на `requestAnimationFrame`, физика фиксированными шагами 1/60 с
с интерполяцией отрисовки (плавно на мониторах с любой частотой), круговые хитбоксы
и пространственная сетка для быстрой проверки столкновений.
