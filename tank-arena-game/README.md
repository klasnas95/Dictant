# Tank Arena

Браузерная арена-шутер с танками в духе diep.io. Написана на чистом HTML5 + CSS + JavaScript (Canvas API), без внешних библиотек и сборщиков.

## Запуск

1. Откройте файл `index.html` в браузере (Chrome, Firefox, Edge или Safari).
2. Введите ник и нажмите «Играть» (или Enter).

Сервер и установка не нужны. Игра работает прямо с диска.

## Управление

| Клавиша / действие | Что делает |
|---|---|
| `W A S D` или стрелки | Движение |
| Мышь | Прицеливание (пушка поворачивается за курсором) |
| `ЛКМ` или `Пробел` | Стрельба (удерживайте для непрерывного огня) |
| `E` | Автострельба (переключатель) |
| `C` | Автоповорот пушки (переключатель) |
| `1`–`8` или клик по панели улучшений | Вложить очко в характеристику |

## Механики

### Арена и полигоны
- Арена 4000×4000 px. Края невидимы: танк просто останавливается у границы. Фон за пределами арены темнее, поэтому граница видна.
- Камера плавно следует за танком. С ростом уровня обзор становится шире.
- На арене есть четыре типа полигонов:
  - **жёлтые квадраты** — легко разрушить, дают мало опыта;
  - **красные треугольники** — прочнее, дают больше опыта;
  - **синие пятиугольники** — крупные и прочные;
  - **фиолетовые альфа-пятиугольники** — очень большие, светятся и дают много опыта.
- Полигоны при столкновении с танком наносят урон. Танк тоже таранит полигоны: при касании он наносит им урон. Разрушенные полигоны появляются снова в случайных местах.

### Опыт и уровни
- Опыт даётся за разрушение полигонов и за убийство танков (игроков и ботов).
- Максимальный уровень — 45. Очко улучшения получают за каждый уровень.
- Очки для таблицы лидеров — весь накопленный опыт.

### Улучшения
За каждый уровень выдаётся очко, которое вкладывается в одну из восьми характеристик (максимум 7 очков на каждую):

1. **Health Regen** — восстановление здоровья
2. **Max Health** — максимальное здоровье
3. **Body Damage** — урон тараном
4. **Bullet Speed** — скорость пули
5. **Bullet Penetration** — сколько целей пуля может пробить
6. **Bullet Damage** — урон пули
7. **Reload** — скорость перезарядки
8. **Movement Speed** — скорость движения

### Эволюция классов
На 15, 30 и 45 уровнях появляется панель выбора класса. Игра при этом продолжается.

- **15 уровень:** Twin, Sniper, Machine Gun, Flank Guard.
- **30 уровень:** два варианта на каждый класс 15 уровня (Triple Shot, Double Twin, Assassin, Hunter, Sprayer, Gunner, Tri-Angle, Quad Flank).
- **45 уровень:** финальные классы (Penta Shot, Battleship, Ranger, Stalker, Hailstorm, Mega Gunner, Trapper, Octo Tank).

### Боты
- На арене 12 ботов со случайными классами и уровнями.
- Боты блуждают по арене, стреляют в ближайшего врага или полигон, держат дистанцию и не врезаются в другие танки.
- Убитые боты возрождаются через несколько секунд.

### Интерфейс
- **Таблица лидеров** (справа вверху) — топ-10 по очкам, игрок выделен.
- **Панель улучшений** (слева внизу) — кликабельные строки со статами.
- **Полоса опыта** (внизу по центру) — текущий уровень и прогресс.
- **Миникарта** (справа внизу) — арена, боты и игрок.
- На экране смерти показаны счёт, уровень и время жизни, есть кнопка «Играть снова».

## Структура проекта

```
tank-arena-game/
├── index.html      # разметка и подключение скриптов
├── style.css       # стили интерфейса
├── README.md       # это описание
└── js/
    ├── config.js   # настройки баланса, полигоны, статы и классы танков
    ├── utils.js    # вспомогательные функции и частицы
    ├── shapes.js   # полигоны и столкновения танков с ними
    ├── bullets.js  # пули и попадания
    ├── tank.js     # танк: статы, прокачка, эволюция, стрельба, физика
    ├── player.js   # управление игроком (клавиатура, мышь)
    ├── bots.js     # ИИ ботов
    ├── render.js   # камера и отрисовка
    ├── ui.js       # интерфейс: экраны, панели, таблица лидеров
    └── main.js     # игровой цикл и точка входа
```

## Технические детали
- Игровой цикл использует `requestAnimationFrame` и `deltaTime`. Шаг времени ограничен 50 мс.
- Столкновения — круговые хитбоксы.
- Движение плавное: скорость подтягивается к желаемой, поэтому отдача от выстрела гаснет мягко.
